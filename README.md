# Power BI Sales Performance Dashboard

## 📊 Project Overview

This project is an interactive Power BI dashboard designed to analyze sales opportunities and track performance across different stages of the sales pipeline.

The dashboard provides a structured view of opportunities, deal values, sales stages, customers, products, and sales representatives.

## 🎯 Objectives

- Track sales opportunities across the complete sales pipeline
- Monitor deal value and opportunity volume
- Analyze sales-stage performance
- Identify won and lost opportunities
- Provide business-focused KPIs for decision-making
- Enable interactive filtering and exploration of sales data

## 📈 Dashboard Features

- Total Opportunity tracking
- Deal Value analysis
- Sales pipeline stage analysis
- Won vs Lost opportunities
- Customer analysis
- Product analysis
- Sales representative performance
- Date-based analysis
- Interactive Power BI filters and visuals

## 🔄 Sales Stages

The dashboard tracks opportunities through stages including:

- Fresh Lead
- NDA
- Customer Audit
- RFQ
- Won
- Lost
- Existing Customers
